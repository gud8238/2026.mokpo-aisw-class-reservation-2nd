# 2026 학교로 찾아가는 AI·SW 체험교실

날짜별 한 학교만 예약할 수 있는 신청 웹앱입니다. 신청 가능한 20일은 화면과 GAS 양쪽에 고정되어 있습니다. 운영 중 날짜를 바꾸려면 `src/model.js`와 `gas/Code.gs`를 함께 수정하세요.

## 시트 연결

원본 Google 시트 **2026. 찾아가는 AISW 체험교실(2학기)**의 `program` G열을 학교 목록으로 읽고, `results`에 신청 결과를 기록합니다. 기존 A~K열은 유지하며 L열에 `교실`을 추가합니다. 첫 신청 시 GAS가 L1 헤더를 씁니다. 기존 `results`의 B열 날짜에 값이 있으면 해당 날짜는 마감됩니다. 조회는 학교명 정확 일치로 동작하며 교사 연락처는 응답에 포함하지 않습니다.

1. 해당 시트에서 **확장 프로그램 → Apps Script**를 열고 `gas/Code.gs`의 내용을 붙여 넣습니다. 독립형 프로젝트를 사용할 경우 스크립트 속성 `SCRIPT_SPREADSHEET_ID`에 원본 시트 ID를 설정합니다.
2. **배포 → 새 배포 → 웹 앱**을 선택합니다. 실행 사용자 **나**, 액세스 권한 **모든 사용자**로 설정하고 `/exec` URL을 복사합니다. 공개 GET에서 학교 목록과 날짜별 마감 여부, POST에서 신청 정보가 처리되므로 운영 계정과 시트 권한을 확인하세요.
3. 로컬 `.env`에 `VITE_GAS_URL=<웹 앱 /exec URL>`을 입력합니다. Netlify에도 동일한 환경 변수를 설정한 뒤 빌드해야 합니다. 이 변수는 공개 API URL이며 비밀 키가 아닙니다.
4. 의존성 설치 없이 `npm test`, `npm run build`, `npm run dev`로 확인합니다. 로컬 개발 서버는 `http://localhost:4173`입니다.
5. GitHub에 푸시한 뒤 `netlify deploy --build --prod`로 배포합니다. GAS 새 버전 배포 시 URL이 바뀌면 환경 변수를 갱신하세요.

## 동작 확인

- 열린 날짜 하나를 선택하고 안내 문구를 확인한 후 학교 자동완성에서 학교를 고릅니다.
- 완료 후 `results` A~L열 기록과 예약 현황 조회를 확인합니다.
- 같은 날짜를 다른 브라우저에서 동시에 신청하면 GAS `LockService` 잠금 안에서 한 건만 성공해야 합니다.
- 전화번호나 교사 이름은 공개 조회 API에서 반환하지 않습니다. 학교명만으로 조회할 수 있으므로 조회 화면에는 학교, 반, 수업 정보가 표시됩니다.

운영 전에는 원본 GAS 웹 앱의 배포와 Netlify 환경 변수 설정이 필요합니다. `.env.example`은 형식 예시입니다.
